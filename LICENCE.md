## 🧩 About

**Stardew Valley overlay** is a curated list of Stardew Valley open-source tools:

- **Overlays** — on-screen helpers, layout notes, tile viewer, farm map switcher
- **Quality-of-Life Helpers** — item catalog, crop manager, overlay notes
- **Research Notes** — farm layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Farm Helpers
- Map Switcher — jump to any farm location for study
- Show Tile Grid — visualize tillable tiles and placement zones
- Crop Notes — track growth stages and watering schedules
- Time Control — adjust in-game clock for layout testing

### 🎨 Catalog & Inventory
- Item Catalog — browse crops, fish, minerals, and artifacts
- Inventory Notes — organize tool and seed loadouts
- Chest Preview — improved visibility for storage layouts

### 🏋️ Farm Layout
- Build Mode Notes — segment study on any farm plot
- Placement Helper — manually align sprinklers and paths
- Friendship Notes — review NPC schedules and gift preferences
